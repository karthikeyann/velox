GPU-Only Operators (3, no core counterpart)

CudfFromVelox

New CPU → GPU boundary operator

Inserted automatically by the cudf driver adapter when transitioning from CPU to GPU execution. Converts Velox RowVector batches to cudf GPU tables, handling host-to-device memory transfer and batching (configurable via velox.cudf.gpu_batch_size_rows).

CudfToVelox

New GPU → CPU boundary operator

Inserted automatically when transitioning from GPU back to CPU execution. Converts cudf tables to Velox RowVector, handling device-to-host transfer. Supports passthrough mode for optimized paths.

CudfBatchConcat

New GPU batch optimization operator

Concatenates multiple small GPU batches into larger ones to improve GPU compute utilization. Small batches underutilize GPU parallelism; this operator amortizes kernel launch overhead.
